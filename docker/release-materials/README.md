# Runtime redistribution materials

The image build copies the complete noVNC 1.5.0 license bundle and SQLCipher
4.6.1 `LICENSE.md` from their hash-verified source archives into
`/usr/share/doc/agent-wechat/licenses`. Their presence is validated during the
build. This directory does not grant or imply permission to redistribute the
repository source or the proprietary WeChat payload; both remain release
blockers documented in `docs/release-audit/P1-C.md`.
