> **Release boundary:** Fork npm, GHCR, and hosted-docs channels remain unavailable until P1-B publishes and verifies them. Use the repository source/local-build path in the meantime.

The fastest way to get started is with the CLI. If you'd rather not manage infrastructure yourself, see [Managed Hosting](/hosting/managed-hosting).

:::note[Prerequisites]
You need **Docker** running on your machine. On macOS, install [Colima](https://github.com/abiosoft/colima) (`brew install colima && colima start`) or [Docker Desktop](https://www.docker.com/products/docker-desktop/). On Linux, install [Docker Engine](https://docs.docker.com/engine/install/).
:::

## 1. Install the CLI

```bash
git clone https://github.com/kyan-du/agent-wechat.git
cd agent-wechat
corepack enable && pnpm install --frozen-lockfile
pnpm build && pnpm build:image
```

This installs the `wx` command globally.

## 2. Start the container

```bash
pnpm cli start
```

After P1-B, an explicit `--image ghcr.io/kyan-du/agent-wechat:<published-semver>` selects the verified fork image. Before then, build locally and plain `wx start` uses the architecture-specific local image; there is no registry fallback.

## 3. Log in to WeChat

```bash
pnpm cli auth login
```

A QR code is displayed in your terminal. Scan it with WeChat on your phone (tap **+** > **Scan**), then confirm the login.

:::tip
Scan the QR code in WeChat if prompted.
:::

## 4. Interact with WeChat

```bash
# List your chats
pnpm cli chats

# Find a chat by name
pnpm cli chats find "John"

# Send a message (--text, --image, or --file)
pnpm cli send <chatId> --text "Hello from agent-wechat!"
pnpm cli send <chatId> --image photo.jpg
pnpm cli send <chatId> --file document.pdf

# Read messages
pnpm cli messages <chatId>

# Download media (images, voice, video) from a message
pnpm cli messages media <chatId> <messageId>
```

## 5. View the container via VNC

Open your browser to `http://localhost:6174/vnc/` to see the WeChat desktop UI running inside the container. You'll be prompted for the auth token — find it with:

```bash
cat ~/.config/agent-wechat/token
```

## 6. Stop the container

```bash
pnpm cli stop
```
