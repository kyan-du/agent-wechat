**Release boundary: P1-B remains unavailable until an owner/legal-approved prerelease publishes and independently verifies npm and GHCR artifacts.** Use a repository checkout and keep the source invocation explicit:

```bash
git clone https://github.com/kyan-du/agent-wechat.git
cd agent-wechat
corepack enable
pnpm install --frozen-lockfile
pnpm build
pnpm build:image
pnpm cli start
pnpm cli auth login
```

Do not describe this as a global installation. After publication is independently verified, the release runbook will provide the exact package-manager installation and uninstall commands. To remove runtime data before uninstalling, use `pnpm cli stop --purge` and confirm the displayed default-instance resource list.

## Clean migration

The first fork prerelease does not migrate historical root-CLI sessions, old image namespaces, or unsafe configuration. Stop old containers and delete only the former root CLI's `sessions` directory at its source-defined data location, then start and authenticate fresh:

- macOS: `rm -rf "$HOME/Library/Application Support/agent-wechat/sessions"`
- Linux: `rm -rf "${XDG_DATA_HOME:-$HOME/.local/share}/agent-wechat/sessions"`
- Windows PowerShell: `Remove-Item -Recurse -Force "$([Environment]::GetFolderPath('ApplicationData'))\agent-wechat\sessions" -ErrorAction SilentlyContinue`

The prerelease is single-instance. Removed `up`, `down`, `update`, and `session` commands only print nonzero migration guidance; they never execute legacy behavior.
