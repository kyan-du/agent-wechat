---
title: REST API
description: API endpoint reference for agent-wechat.
---

The agent-wechat server exposes a REST API on port `6174`. All requests require a `Bearer` token in the `Authorization` header.

## Authentication

```
Authorization: Bearer <token>
```

## Endpoints

### Chats

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/chats` | List chats (with unread counts) |
| `GET` | `/api/chats/:id` | Get a specific chat |
| `POST` | `/api/chats/:id/open` | Open a chat in the WeChat UI |

### Messages

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/messages/:chatId` | List messages in a chat |
| `POST` | `/api/messages/send` | Send a message (text, image, or file) |
| `GET` | `/api/messages/:chatId/media/:localId` | Download a media attachment |

`POST /api/messages/send` is processed through the server-side outbound safety queue. The request body accepts text, image, or file payloads and an optional `idempotencyKey` string. Reusing the same `idempotencyKey` while the first request is pending returns `429 Too Many Requests`; reusing it after completion returns the cached result for a short TTL so clients can retry safely after uncertain network outcomes without creating a second send.

If the outbound queue is full, the server returns `429 Too Many Requests` with a `Retry-After` header and a JSON body such as:

```json
{
  "success": false,
  "errorCode": "QUEUE_FULL",
  "error": "Outbound send queue is full"
}
```

If outbound sending is disabled by read-only mode, the endpoint returns `503 Service Unavailable` with `errorCode: "OUTBOUND_DISABLED"`.

`GET /api/status/outbound` reports queue `queueDepth`, `queueCapacity`, `availableCapacity`, current read-only state, idempotency cache size, and configured spacing/TTL values for operational monitoring. Its `diagnostics` object contains monotonic counters for enqueue/completion/failure, `429`, TTL expiry, pause/resume, duplicate suppression, uncertain sends, and budget/quiet-hours rejection, plus queue-wait and actual-send-interval durations. `chatSelectDiagnostics` reports open/verify fallback, Frida attach, timeout, and failure counts.

These diagnostic objects intentionally contain only counters, durations, booleans, configuration values, and stable codes. They never include message text, contact display names or IDs, credentials, QR data, file paths, or base64 media.

Chat open and outbound send failures use stable `errorCode` values. Frida fallback failures are distinguishable as `FRIDA_ATTACH_FAILED`, `FRIDA_ATTACH_TIMEOUT`, `FRIDA_ENUMERATION_FAILED`, `FRIDA_HOOK_FAILED`, or `TARGET_CONFIRMATION_FAILED`. A timeout, unsupported build, unknown target, duplicate display identity, or unverified post-selection target fails closed before the send action. Once the Return/send action may have been attempted, `commitAttempted: true` and an uncertain code such as `send_commit_uncertain` distinguish the terminal result from a safe pre-send failure.

### Auth

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/status/outbound` | Inspect outbound send queue pressure and safety settings |
| `GET` | `/api/auth/status` | Check login status |
| `POST` | `/api/auth/logout` | Log out of WeChat |
| `WS` | `/api/ws/login` | WebSocket for login flow (QR code events) |

### Contacts

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/contacts` | List all contacts |

### Sessions

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/sessions` | List sessions |
| `POST` | `/api/sessions` | Create a session |
| `POST` | `/api/sessions/:id/start` | Start a session |
| `POST` | `/api/sessions/:id/stop` | Stop a session |
| `DELETE` | `/api/sessions/:id` | Delete a session |

### Debug

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/screenshot` | Take a screenshot |
| `GET` | `/api/a11y` | Dump the accessibility tree |

### VNC

| Path | Description |
|------|-------------|
| `/vnc/` | Browser-based VNC viewer (noVNC) |
